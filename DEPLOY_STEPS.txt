1. Upload these files to a new GitHub repository:
   bot.py
   requirements.txt
   render.yaml
   README.md

2. In Render: New + -> Web Service -> connect the GitHub repo.

3. Build Command:
   pip install -r requirements.txt

4. Start Command:
   python bot.py

5. Environment:
   TELEGRAM_BOT_TOKEN = NEW BotFather token
   TWELVE_DATA_API_KEY = your Twelve Data API key
   PORT = 10000

6. Deploy.

7. Telegram:
   /start
   /signal
   /auto
   /stop

IMPORTANT:
- Never publish the Telegram bot token.
- Revoke any token previously exposed in chat and create a new one.
