1. Create a Telegram bot using @BotFather and copy the bot token.
2. Upload this folder to GitHub or use it as your Render service source.
3. Create a Render Web Service.
4. Build command: pip install -r requirements.txt
5. Start command: python bot.py
6. Add TELEGRAM_BOT_TOKEN with your BotFather token.
7. Add TRADEPILOT_BACKEND_URL=https://tradepilot-live-backend.onrender.com
8. Deploy.
9. Open the bot in Telegram and send /start.
10. Use Auto Signal, choose a symbol and timeframe, then the bot will watch for new candles.
